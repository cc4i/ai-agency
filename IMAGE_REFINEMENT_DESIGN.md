# Interactive Image Refinement Design

## Overview

Add interactive refinement capability to the Art Director agent, allowing users to iteratively improve generated hero images through natural language feedback.

## User Experience

```
User: "Option 1 is nice, but I want to add modern elements"
Producer: *analyzes feedback and refines image 1*
Producer: "Here's the refined version with modern design elements..."

User: "Can you make option 2 brighter with more vibrant colors?"
Producer: *refines image 2*
```

### Phase 2: Multi-Image Batch Refinement

Support feedback like: "Make all images brighter"

```python
async def refine_all_images(
    self,
    all_images: List[ImageAsset],
    global_feedback: str,
    product_context: Dict[str, Any],
) -> List[ImageAsset]:
    """Apply same feedback to multiple images in parallel."""
    tasks = [
        self.refine_image(img, global_feedback, product_context)
        for img in all_images
    ]
    return await asyncio.gather(*tasks)
```

### 4. Version Mixing & Rollback

**Simple Rollback** - Restore any previous version:
```python
User: "Go back to version 2"
→ System restores v2 as current (no regeneration)
→ Instant response
```

**Version Mixing** - Combine aspects from multiple versions:
```python
User: "Take version 2 but keep the brightness from version 4"

System analyzes:
- v2: Base composition, modern UI elements
- v4: Brightness/saturation parameters

Generates new v5:
- Uses v2 image as reference (maintains composition)
- Applies brightness adjustments from v4
- Creates hybrid combining best of both
```

This enables creative exploration without losing previous work.

```python
@tool
def refine_hero_image(variation_number: int, feedback: str) -> dict:
    """
    Refine a specific hero image based on user feedback, creating a new version.

    Use this when the user wants to improve or modify ONE specific image variation.
    Creates a new version (v2, v3, etc.) while preserving the original.

    The refinement process:
    1. Analyzes user feedback to determine what to keep vs. change
    2. Uses the original image as reference for consistency
    3. Generates refined image maintaining brand alignment
    4. Validates that feedback was addressed (quality score >= 0.7)
    5. Returns new version with version history

    Args:
        variation_number (int): Which image variation to refine (1-4)
        feedback (str): User's refinement request describing desired changes.
                       Be specific about what they want modified.
                       Examples: "add modern UI elements", "make it brighter",
                                "dial back the holographic overlays"

    Returns:
        dict: {
            "success": bool,
            "refined_image": ImageAsset with new version,
            "version_number": int (e.g., 2 for v2),
            "original_version": int (always 1 for first refinement),
            "feedback_applied": str,
            "quality_score": float (0.0-1.0)
        }

    Usage patterns:
        - "Option 1 is nice, but add modern elements"
          → refine_hero_image(variation_number=1, feedback="add modern elements")

        - "Make option 2 brighter with more vibrant colors"
          → refine_hero_image(variation_number=2, feedback="make brighter with vibrant colors")

        - "Option 3 needs the background blurred"
          → refine_hero_image(variation_number=3, feedback="blur the background")

    Note: Max 5 refinement iterations per image. Returns error if limit exceeded.
    """
    project_id = get_current_project_id()

    try:
        # Load project brief
        brief = await load_project_brief(project_id)

        # Get original image (or current version if already refined)
        if variation_number < 1 or variation_number > 4:
            return {"success": False, "error": f"Invalid variation number: {variation_number}. Must be 1-4."}

        current_image = brief["hero_images"][variation_number - 1]

        # Check max iterations
        if current_image.get("refinement_iteration", 0) >= 5:
            return {
                "success": False,
                "error": "Maximum refinement iterations (5) reached. Consider selecting existing version or generating new image."
            }

        # Call Art Director workflow
        from app.workflows.art_director_workflow import ArtDirectorWorkflow
        workflow = ArtDirectorWorkflow()

        refined_image = await workflow.refine_image(
            original_image=current_image,
            user_feedback=feedback,
            product_context={
                "product_name": brief["product_name"],
                "product_category": brief["product_category"],
                "theme": brief["theme"],
                "brand_tone": brief["brand_tone"],
                "key_features": brief["key_features"],
            }
        )

        # Update project brief with refined image
        brief["hero_images"][variation_number - 1] = refined_image

        # Update refinement history
        if "image_refinement_history" not in brief:
            brief["image_refinement_history"] = {}

        original_id = current_image.get("asset_id")
        if original_id not in brief["image_refinement_history"]:
            brief["image_refinement_history"][original_id] = {
                "original_asset_id": original_id,
                "refinements": [],
                "feedback_history": [],
                "iteration_count": 0
            }

        brief["image_refinement_history"][original_id]["refinements"].append(refined_image)
        brief["image_refinement_history"][original_id]["feedback_history"].append(feedback)
        brief["image_refinement_history"][original_id]["iteration_count"] += 1

        await save_project_brief(brief)

        # Emit WebSocket event
        await broadcast_event({
            "type": "image_refined",
            "variation_number": variation_number,
            "refined_image": refined_image,
            "version_number": refined_image.get("refinement_iteration"),
        })

        return {
            "success": True,
            "refined_image": refined_image,
            "version_number": refined_image.get("refinement_iteration"),
            "feedback_applied": feedback,
            "quality_score": refined_image.get("generation_params", {}).get("score", 0.0),
        }

    except Exception as e:
        logger.error(f"Error refining hero image: {e}")
        return {"success": False, "error": str(e)}


@tool
def refine_all_hero_images(feedback: str) -> dict:
    """
    Refine ALL 4 hero images with the same feedback, processing in parallel.

    Use this when the user wants to apply the same change to all image variations.
    All 4 images are refined simultaneously for speed (~20 seconds total).

    Args:
        feedback (str): Global change to apply to all images.
                       Examples: "make brighter", "increase color vibrancy",
                                "add more energy", "reduce saturation"

    Returns:
        dict: {
            "success": bool,
            "refined_images": List[ImageAsset] (4 refined images),
            "feedback_applied": str,
            "average_quality_score": float
        }

    Usage patterns:
        - "All images feel too dark"
          → refine_all_hero_images(feedback="increase brightness")

        - "Make them all more vibrant"
          → refine_all_hero_images(feedback="increase color vibrancy")

        - "All images need more energy"
          → refine_all_hero_images(feedback="add more dynamic energy")
    """
    project_id = get_current_project_id()

    try:
        brief = await load_project_brief(project_id)

        # Refine all 4 images in parallel
        from app.workflows.art_director_workflow import ArtDirectorWorkflow
        workflow = ArtDirectorWorkflow()

        refined_images = await workflow.refine_all_images(
            all_images=brief["hero_images"],
            global_feedback=feedback,
            product_context={
                "product_name": brief["product_name"],
                "product_category": brief["product_category"],
                "theme": brief["theme"],
                "brand_tone": brief["brand_tone"],
                "key_features": brief["key_features"],
            }
        )

        # Update brief
        brief["hero_images"] = refined_images
        await save_project_brief(brief)

        # Calculate average score
        scores = [img.get("generation_params", {}).get("score", 0.0) for img in refined_images]
        avg_score = sum(scores) / len(scores) if scores else 0.0

        return {
            "success": True,
            "refined_images": refined_images,
            "feedback_applied": feedback,
            "average_quality_score": avg_score,
        }

    except Exception as e:
        logger.error(f"Error refining all images: {e}")
        return {"success": False, "error": str(e)}


@tool
def select_image_version(variation_number: int, version_number: int) -> dict:
    """
    Select a specific version of an image from refinement history (rollback).

    Use when the user wants to go back to a previous version of a refined image.
    This restores an earlier version as the current version without regeneration.

    Args:
        variation_number (int): Which image variation (1-4)
        version_number (int): Which version to restore (1=original, 2=v2, 3=v3, etc.)

    Returns:
        dict: {
            "success": bool,
            "selected_version": ImageAsset,
            "version_number": int,
            "description": str
        }

    Usage patterns:
        - "Go back to version 2 of option 1"
          → select_image_version(variation_number=1, version_number=2)

        - "I prefer version 1 of option 3"
          → select_image_version(variation_number=3, version_number=1)

        - "Restore the original version of option 2"
          → select_image_version(variation_number=2, version_number=1)
    """
    project_id = get_current_project_id()

    try:
        brief = await load_project_brief(project_id)

        # Get refinement history for this variation
        current_image = brief["hero_images"][variation_number - 1]
        original_id = current_image.get("asset_id")

        # If version 1, use original
        if version_number == 1:
            # Find original in history or use current if no refinements
            target_version = current_image  # Simplified - should lookup in history
        else:
            # Get from refinement history
            history = brief.get("image_refinement_history", {}).get(original_id, {})
            refinements = history.get("refinements", [])

            if version_number - 2 >= len(refinements):
                return {
                    "success": False,
                    "error": f"Version {version_number} not found. Only {len(refinements) + 1} versions exist."
                }

            target_version = refinements[version_number - 2]

        # Update current image
        brief["hero_images"][variation_number - 1] = target_version
        await save_project_brief(brief)

        return {
            "success": True,
            "selected_version": target_version,
            "version_number": version_number,
            "description": target_version.get("description", ""),
        }

    except Exception as e:
        logger.error(f"Error selecting image version: {e}")
        return {"success": False, "error": str(e)}

### 3. Feedback Analysis System Prompt

**File**: `backend/app/workflows/art_director_workflow.py` (new method)

```python
async def _analyze_user_feedback(
    self,
    original_prompt: str,
    user_feedback: str,
    image_b64: str,
) -> Dict[str, Any]:
    """
    Analyze user feedback using Gemini 2.5 Flash with vision.

    Extracts what to KEEP vs. CHANGE from user's refinement request
    by analyzing both the image and the feedback.

    Args:
        original_prompt: The prompt used to generate the original image
        user_feedback: User's refinement request (e.g., "add modern elements")
        image_b64: Base64-encoded original image for visual analysis

    Returns:
        {
            "keep_aspects": List[str],
            "change_aspects": List[str],
            "refinement_strategy": str
        }
    """

    analysis_system_prompt = """
You are an expert Image Analysis AI helping refine product marketing images.

Your job: Analyze user feedback on an image to determine what to KEEP and what to CHANGE.

# ANALYSIS APPROACH

1. **Understand the Feedback**
   - What is the user explicitly praising? (e.g., "I like the lighting")
   - What is the user requesting to change? (e.g., "but add modern elements")
   - What is implied to stay the same? (composition, positioning, etc.)

2. **Visual Analysis** (from image)
   - Identify current composition, lighting, colors, styling
   - Note prominent features that user might want preserved
   - Detect elements that might need modification

3. **Extract Keep/Change Lists**
   - KEEP: Elements user likes OR elements not mentioned (assume preservation)
   - CHANGE: Explicit requests for additions, modifications, or removals

# OUTPUT FORMAT

Return valid JSON only (no markdown):
{
    "keep_aspects": [
        "Specific aspect 1 to preserve",
        "Specific aspect 2 to preserve",
        ...
    ],
    "change_aspects": [
        "Specific change 1 to implement",
        "Specific change 2 to implement",
        ...
    ],
    "refinement_strategy": "One-sentence strategy for refinement"
}

# EXAMPLES

**Example 1**:
Feedback: "Option 1 is great, but add modern UI elements"
Keep: ["Dramatic lighting", "Product centered", "Ocean-blue background", "16:9 composition"]
Change: ["Add modern UI overlays", "Include holographic elements", "Tech graphics"]
Strategy: "Maintain hero product shot composition and lighting, overlay modern tech UI elements"

**Example 2**:
Feedback: "Make it brighter and more vibrant"
Keep: ["Composition", "Product positioning", "Background style", "Overall aesthetic"]
Change: ["Increase brightness", "Boost color saturation", "Enhance vibrancy"]
Strategy: "Maintain all compositional elements, adjust exposure and color saturation"

**Example 3**:
Feedback: "I love the composition but dial back the holographic overlays"
Keep: ["Composition", "Framing", "Product positioning", "Base lighting"]
Change: ["Reduce holographic overlay intensity", "Make UI elements more subtle", "Soften tech graphics"]
Strategy: "Preserve composition completely, reduce visual prominence of overlay elements"

# IMPORTANT RULES

- KEEP aspects should be specific (not "everything else")
- CHANGE aspects should be actionable instructions
- If feedback is vague, infer reasonable keep/change from image context
- Refinement strategy should be implementable as an image generation prompt
- Always preserve product as focal point unless explicitly told otherwise
"""

    user_prompt = f"""
# ORIGINAL IMAGE GENERATION PROMPT
{original_prompt}

# USER'S REFINEMENT FEEDBACK
{user_feedback}

# TASK
Analyze the image and feedback. Return JSON with keep_aspects, change_aspects, and refinement_strategy.
"""

    try:
        from app.services.google_ai_client import genai_client
        from google.genai.types import Part

        response = await genai_client.aio.models.generate_content(
            model="gemini-2.5-flash",
            contents=[
                Part(text=user_prompt),
                Part(inline_data={'mime_type': 'image/png', 'data': image_b64})
            ],
            config=types.GenerateContentConfig(
                temperature=0.3,  # Lower for consistent analysis
                system_instruction=analysis_system_prompt,
                response_mime_type='application/json'
            )
        )

        # Parse JSON response
        import re
        text = response.text.strip()
        text = re.sub(r'^```json?\s*', '', text)
        text = re.sub(r'\s*```$', '', text)

        analysis = json.loads(text)

        logger.info(
            f"Feedback analysis: Keep {len(analysis['keep_aspects'])} aspects, "
            f"Change {len(analysis['change_aspects'])} aspects"
        )

        return analysis

    except Exception as e:
        logger.error(f"Error analyzing feedback: {e}")
        # Fallback: simple text-based analysis
        return {
            "keep_aspects": ["composition", "product positioning", "overall style"],
            "change_aspects": [user_feedback],
            "refinement_strategy": f"Apply user's requested change: {user_feedback}"
        }
```

### Version Mixing with Modification
```python
async def refine_version_with_attributes(
    self,
    base_version: ImageAsset,
    attribute_sources: Dict[str, ImageAsset],
    product_context: Dict[str, Any],
) -> ImageAsset:
    """
    Create new version by combining base with attributes from other versions.

    Args:
        base_version: The version to use as foundation
        attribute_sources: Dict mapping attributes to source versions
            e.g., {"brightness": v4, "saturation": v3}
        product_context: Product details

    Returns:
        New refined ImageAsset combining requested attributes

    Example:
        User: "Take v2 but keep brightness from v4"
        → base_version = v2
        → attribute_sources = {"brightness": v4}
        → Generates v5 with v2's composition + v4's brightness
    """
```

**Implementation Flow**:
1. Analyze base version (extract prompt, parameters)
2. Analyze attribute source versions (extract requested attributes)
3. Generate refinement prompt combining base + attributes
4. Use base image as reference for consistency
5. Generate new image with merged attributes
6. Create new ImageAsset with both parent references
